# Antigravity Pair Programmer Rules

- **Auto-run Policy**: Always run terminal commands, edit files, and proceed with execution immediately without asking for user confirmation (`always-proceed` behavior).
- **Execution Workflow**: Do not block on planning mode or step approval. Proceed directly to implementation and verify outcomes afterwards.
- **Zero Questions / Zero Blocking Policy**: Never use `ask_question`. Never ask clarifying questions, never ask for design approvals, and never pause execution to wait for user input. If any requirement is open or ambiguous, decide autonomously based on best industry standards and implement immediately.
